## 🔄 Version Control

Git and GitHub are used to manage the development history of this repository.

The general workflow is:

```text
Complete Task
     ↓
Test the Work
     ↓
Stage Changes
     ↓
Commit Changes
     ↓
Push to GitHub
```

This helps track changes and maintain the progress of the coursework.
